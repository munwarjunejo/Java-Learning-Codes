# Java Learning Codes

Beginner-friendly Java programs, starting from the basics.

## Basic Programs

1. `HelloWorld.java` — print a message
2. `Variables.java` — declare and display variables
3. `UserInput.java` — read input with `Scanner`
4. `EvenOdd.java` — check whether a number is even or odd

## Run a Program

```bash
javac basic/HelloWorld.java
java -cp basic HelloWorld
```

Each file contains one public class. The filename and class name must match.
